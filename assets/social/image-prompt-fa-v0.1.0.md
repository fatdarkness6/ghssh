## Generation prompt

Use case: ads-marketing.
Create ONE polished, memorable launch image for a Persian LinkedIn post about ghssh v0.1.0, a real Linux command-line tool that temporarily switches between two GitHub SSH identities and restores the previous setup. This is a finished social post image, not a web page or a screenshot mockup.
Canvas: portrait 4:5, ideally 1536 x 1920. Mobile-first visual hierarchy, generous safe margins, clean editorial product-launch art direction. Refined dark charcoal background, ivory typography, restrained teal and violet accents, subtle realistic material textures; avoid generic cyberpunk and stock hacker imagery.
Central concept: two distinct intact metallic SSH keys, each paired with a sleek floating identity card, connected by TWO clear elegant curved arrows showing switching there and back. One card says ACCOUNT 01, the other ACCOUNT 02. Distinct teal/violet accents make the two identities recognizable. The keys have satisfying tactile brushed-metal 3D detail and believable soft shadows. Both keys remain intact; no deleted/broken keys or destructiveness. No fabricated browser-login interface. Keep the composition spacious and recognizable even as a feed thumbnail.
Top: very large beautifully set modern Persian sans-serif headline, fully connected correct Persian script, right-to-left reading, exact text on two lines:
"دو اکانت گیت‌هاب؛"
"یک دردسر تکراری."
Below the hero illustration, prominent monospaced product wordmark: "ghssh".
A single tidy dark terminal panel beneath it contains these EXACT two left-to-right commands on separate lines:
"$ ghssh switch github_second"
"$ ghssh switch --back"
Use readable large crisp monospaced type. These two commands should be accurate and easy to read; no fake command output.
Small tasteful footer: "v0.1.0" and "github.com/fatdarkness6/ghssh".
Constraints: excellent Persian spelling and joined glyphs, exact command text, no additional slogans or body paragraphs, no invented statistics or endorsement, no personal portrait, no watermark, no clutter, no tiny illegible text. The illustration should make the problem of switching accounts feel concrete; the overall design should feel like thoughtful open-source developer tooling, not a generic advertisement.
